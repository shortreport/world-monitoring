============================================================
  画像貼り付けマクロ セットアップ手順
============================================================

【ファイル構成】
  InsertImage_Module.bas  ... メインロジック（画像パス・サイズ設定）
  InsertImage_Form.frm    ... 選択フォーム

------------------------------------------------------------
手順1: 画像パスの設定
------------------------------------------------------------
InsertImage_Module.bas をメモ帳で開き、以下の行を編集:

  Const IMG_PATH_1 = "C:\画像フォルダ\画像1.png"  ← 実際のパスに変更
  Const IMG_PATH_2 = "C:\画像フォルダ\画像2.png"
  Const IMG_PATH_3 = "C:\画像フォルダ\画像3.png"

  Const IMG_LABEL_1 = "画像1"  ← フォームに表示する名前
  Const IMG_LABEL_2 = "画像2"
  Const IMG_LABEL_3 = "画像3"

デフォルトの位置・サイズも変更できます（単位: cm）:
  DEFAULT_LEFT   = 1.5  （左端からの距離）
  DEFAULT_TOP    = 2.0  （上端からの距離）
  DEFAULT_WIDTH  = 6.0  （幅）
  DEFAULT_HEIGHT = 4.5  （高さ）

------------------------------------------------------------
手順2: Wordへのインポート
------------------------------------------------------------
1. Wordを開く（どのファイルでも可）
2. Alt + F11 → VBAエディタを開く
3. メニュー「ファイル」→「ファイルのインポート」
4. InsertImage_Module.bas を選択 → インポート
5. 同様に InsertImage_Form.frm を選択 → インポート
   ※ .frm と同じフォルダに .frx ファイルが自動生成されます

------------------------------------------------------------
手順3: フォームのコントロール作成（初回のみ）
------------------------------------------------------------
.frm インポート後、フォームを手動で作成する必要があります。

1. VBAエディタ左のツリーで「Forms」→「frmInsertImage」をダブルクリック
2. ツールボックスから以下を配置:

  [ラベル] Caption: "使用する画像を選択してください"

  [OptionButton] Name: opt1  （画像1）
  [OptionButton] Name: opt2  （画像2）
  [OptionButton] Name: opt3  （画像3）

  [ラベル] Caption: "位置・サイズ (cm)"

  [ラベル] Caption: "左端から"
  [TextBox]  Name: txtLeft

  [ラベル] Caption: "上端から"
  [TextBox]  Name: txtTop

  [ラベル] Caption: "幅"
  [TextBox]  Name: txtWidth

  [ラベル] Caption: "高さ"
  [TextBox]  Name: txtHeight

  [CommandButton] Name: btnInsert   Caption: "貼り付け"
  [CommandButton] Name: btnCancel   Caption: "キャンセル"

------------------------------------------------------------
手順4: マクロの実行
------------------------------------------------------------
方法A: Alt + F8 →「InsertImageMain」→「実行」
方法B: クイックアクセスツールバーにボタンを追加して1クリックで起動

------------------------------------------------------------
使い方
------------------------------------------------------------
1. Wordで貼り付けたいファイルを開く
2. マクロ「InsertImageMain」を実行
3. フォームで画像を選択
4. 必要なら位置・サイズを変更（cmで入力）
5. 「貼り付け」をクリック
6. Word上で画像をドラッグして位置を微調整可能
   （図の書式設定でサイズも変更可能）
