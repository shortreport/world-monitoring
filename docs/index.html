The World in Brief

  • トランプ政権が中国、欧州連合、日本、韓国、インドなど幅広い取引相手からの商品に対し最大20%の関税を提案。最高裁が却下した以前の関税に代わるもので、不公正な貿易慣行の調査対象は16か国に及ぶ。
  • 米国株がテック売却から小幅反発。ナスダック100は0.6%低下し、エヌビディアの株価は3.9%下落、アンスロピックの株価は新規公開価格の83ドル以下で推移。
  • イーロン・マスク傘下のスペースエックスが100万基の衛星打ち上げを連邦通信委員会に承認され、宇宙データセンター建設計画が前進。ただし実現は高額の事業になる見通し。
  • カイロの環状道路で火災発生、少なくとも30人が死亡し15人が負傷。ガソリンタンクローリーの転倒が出火原因で、エジプトの道路安全対策の課題が浮き彫りに。
  • トッド・ボーリー率いる投資家コンソーシアムがロシアの石油大手ルコイルの国際資産買収に合意。米国財務省の承認次第で100億ドル相当の証券をスワップ。
  • バングラデシュ政府が衣料産業労働者の月間最低賃金を17,000タカ（136ドル）に引き上げることを提案。36%の上昇で、高インフレに直面する労働者の激しい抗議を受けた措置。
  • アイオワ州の弾薬工場で20年前の火薬化学物質5トン近くの爆発処理を実施。除去が危険と判断された鉛アジ化物の管理爆破で、中西部への有害粉じん拡散の懸念を克服。
