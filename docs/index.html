  • アメリカ航空母艦USSエイブラハム・リンカーン号が中東を離脱。イラン戦争開始の3ヶ月前となる11月から配備され、艦内の士気低下と食料不足が報告されるなか、トランプ政権は状況が過度に表現されたと主張。
