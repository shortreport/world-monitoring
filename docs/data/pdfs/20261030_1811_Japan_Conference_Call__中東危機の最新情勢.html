エスカレーションが基本シナリオに

ユーラシア・グループ（EG）は、米国による対イラン軍事行動のエスカレーションの確率を65%に引き上げ、基本シナリオとした。それまでの基本シナリオだった対立状態の継続は15%に引き下げられた。合意の確率は10%から20%へ小幅に引き上げられたが、これはイランの譲歩に意味のある変化があったことではなく、現状が米国にとって持続不可能であることを反映している（2026年10月15日「ホルムズ海峡でのイランの攻撃が、中間選挙後に米国の軍事行動拡大を余儀なくさせる可能性が高い」）。

基本シナリオ変更の引き金となったのは、地域のエネルギー輸送を回復させようとする米国主導の取り組みをイランが消耗させることに成功したことだ。地域からの輸出量は9月下旬までに一時、日量1800万バレルを上回る水準、すなわち実質的に戦前の水準まで回復していたが、イランは船舶への攻撃を急激にエスカレートさせることで対応した。9月28日以降、船舶への命中が確認された事例は24件を超え、ホルムズ海峡に集中しているものの、ペルシャ湾とオマーン湾にも広がっている。船舶追跡データ（ケプラー）の速報値によると、地域の輸送量は現在、日量約1400万～1500万バレルで、ホルムズ海峡の通航量は日量約1000万バレル。英海事機関UKMTOは、すべての攻撃が報告されているわけではないと認めており、実際の阻止行動のペースは公表データが示すより速い可能性が高い。

エネルギー市場への影響

北海ブレント原油の価格は、エスカレーションが現実化するにつれ、1バレル＝110～125ドルの範囲に移行すると予想する。上振れリスクは、海運のさらなる混乱だけでなく、米国の攻撃への報復としてイランが地域のエネルギーインフラを攻撃する可能性からも生じる。

中間留分については、ポーランドなど欧州での製油所拡張、米メキシコ湾岸の精製能力増強、インドからの出荷により、短期的には一定の緩和が見込まれる。ロシアとのディーゼル燃料購入取り決めも、国内燃料価格を管理するために政権がどこまで踏み込む用意があるかを示すものだ。これらの要因は、11月半ばまでに軍事行動を取ることに対する緩衝材となる可能性がある。

米国のエスカレーション：時期、規模、制約

米国は、二つの主要な装備区分に依存し、およそ2週間にわたって空爆活動を拡大する可能性が高い。一つは米本土とインド洋の基地から（米国がプレゼンスを縮小した西欧からではなく）発進する長距離爆撃機だ。もう一つは海軍航空戦力だ。米軍のF15が撃墜され、イランの防空能力が米国の予想を上回ることが示された後、米国はイラン上空への有人航空機の出撃をおおむね取りやめている。トマホークやその他の無人スタンドオフ兵器は大幅に減少している。

主要な制約は、大型貫通爆弾（MOP）だ。地下深くに埋設された備蓄や核施設を標的とするために必要なこの兵器の現在の在庫は「十数発」とされる。米国が、イランのミサイルと無人機の備蓄を破壊し、核計画を弱体化させ、譲歩を強いるという、表明されている軍事目標を完全に達成できるかについて、われわれは懐疑的だ。しかし、米政権は別の見方をしているようだ。MOAB（大規模爆風爆弾）の使用可能性に関する報道は、作戦計画ではなくシグナル発信だ。MOABは広範囲を制圧する兵器であり、強化された地下の標的には適していない。

中間選挙がトランプの戦略を動かしているわけではないが、時期には影響を及ぼしている。トランプは共和党が議席を失う可能性を気にしていないようだ。11月半ばまで遅らせれば、党内からの批判を回避できるほか、第3の空母打撃群を、すでに戦域に展開している二つの空母打撃群と数週間にわたり重複して展開し、準備を進めることができる。

イランの戦略：エスカレーションではなく消耗戦略

イランの指導部は、最高指導者ハメネイ師が公の場への露出が減り、現在は集団指導体制となっており、消耗戦略を軸に結束している。目的は、米国の過剰な対応を誘発したり、イラン自身のミサイルと無人機の在庫を枯渇させたりすることなく、エネルギー価格を高止まりさせ、米国への圧力を維持することである。

イランの交渉姿勢は依然として強硬だ。イランがオマーンと共同でホルムズ海峡を管理することの承認、6月の覚書（MoU）の復活、資金凍結解除、米国による封鎖の解除を求めている。米国は、核での譲歩、具体的にはイランの高濃縮ウラン備蓄と今後の濃縮の要求へと再び転じたが、イランはまず6月の覚書に盛り込まれた見返りを受け取るまで交渉しない方針だ。イランのアッバス・アラグチ外相は国連総会に合わせて7項目の提案を提示したが、具体的な要求は公表されていない。イラン指導部は、トランプ政権と持続的な合意を結べる可能性を事実上排除しており、その根拠として6月の覚書に対する米国の違反といらんのみなしている行為を挙げている。イランのメディアはすでに、トランプ後、すなわち2029年1月以降に外交的関与を再開する可能性を論じている。

イエメン：関連戦域、短期的な石油リスクは限定的

バベルマンデブ海峡を含むイエメン西岸沿いで、フーシ派の攻勢により失った領土を奪還するためのサウジアラビア支援の作戦は、順調に進んでいない。フーシ派をバベルマンデブ海峡から北へ押し戻しているとの当初の進展報告は、誇張されていると評された。フーシ派は現在、タイズ周辺で封鎖を実施しており、サウジが支援する陣地への攻撃を続けている。

サウジの看板イベントである未来投資イニシアチブ（FII）会議は中止された。これはムハンマド皇太子（MBS）への圧力を示すシグナルである。リヤド、ダンマン、ジッダを含む空港はおおむね閉鎖されている。

重要なのは、フーシ派が、原油価格を大きく動かしたり、米国の直接介入を招いたりするような形でサウジのエネルギーインフラを攻撃することを意図的に避けている点である（2026年10月14日「フーシ派、市場に影響を与えるサウジアラビア石油施設への攻撃を回避する公算大」）。オマーンで成立したとされる米国とフーシ派の合意により、フーシ派がバベルマンデブ海峡を通過するサウジ以外の船舶への攻撃を自制する見返りとして、米国はイエメン紛争への関与を控えてきた。これはフーシ派の意図的な戦略だ。イエメンに関してトランプの判断を変えるような行動を避ける一方、MBSとトランプの関係に緊張を加えている。

米国はサウジ軍に戦場の情報と精密誘導弾（PGM）を提供している。エジプトのシシ大統領が軍事支援を公に申し出たことを受け、エジプトが参入する場合、最も可能性が高いのは、エジプト空軍の戦力がサウジの防空を支援し、サウジの航空機を攻撃作戦に振り向けられるようにする形だ。エジプト議会の承認が見込まれているものの、まだ確保されていない。また、エジプトは1960年代のナセル大統領時代に多大な代償を伴う介入を行った経緯から、歴史的にイエメンに敏感だ。サウジまたはカタールからの金銭的補償が、エジプトのいかなる判断にも含まれると想定されている。

主なウオッチポイント

  • ホルムズ海峡の通航量：地域からの輸出が安定するのか、それとも日量1400万～1500万バレルの水準に向けて減少し続けるのかが、米国によるエスカレーションの時期を左右する主要な短期的圧力指標である。
  • 米軍戦力の再配置：カタールのアルウデイド空軍基地などに前方展開している米軍機。歴史的に米国はエスカレーションに先立ち、これらをより安全な場所へ退避させる。
  • 第3の空母打撃群の展開：すでに展開している二つの空母打撃群と一定期間重複して展開することが、米国による攻撃拡大の実質的前提条件である。
  • フーシ派の標的選定行動：フーシ派が、バベルマンデブ海峡を通過する米国またはサウジアラビア以外の船舶に対する事実上の自制を破るかどうかが、米国のイエメンへの直接関与を引き起こす最も可能性の高い要因だ。
  • イスラエル選挙の結果：連立協議での混乱や再選挙の可能性がある。ネタニヤフ首相または後継政権が、米国による対イラン軍事行動のエスカレーションへのイスラエルの参加を要請または可能にするかどうかを注視すべきだ。
  • イラク民兵の活動：イラン革命防衛隊（IRGC）が隠れみのとして、イラクを拠点とした代理勢力にサウジのエネルギーインフラを攻撃させる潜在的リスクが残る。

クライアントからの質問

イランを巡るエスカレーションの時期――米中間選挙前か後か？　イランは消耗戦略に沿って米国に先にエスカレートさせることを選び、待つ可能性の方が高いと評価している。トランプのこれまでの実績を踏まえれば、中間選挙前にイランの圧力によって引き出された合意は、存続期間が極めて短いものになるだろう。

イエメンにおけるエジプトの役割： クライアントは、エジプトの関与が象徴的なものなのか、軍事的に意味のあるものなのかを尋ねた。エジプト空軍の戦力は、サウジの航空機を攻撃作戦に振り向けるうえで意味のある役割を果たし得るが、米国の直接関与以外のものが現在の紛争の流れを変える可能性は低い。

米国の出口戦略： われわれは、現政権下で持続的な解決に至ることには懐疑的だ。より可能性が高いパターンは、一時的なエスカレーションと緊張緩和を繰り返す循環であり、双方とも資源上の制約とエネルギー市場の圧力によって行動を制限される。イラン核合意（JCPOA）のプロセスに類似した多国間外交の枠組みには、別の米政権が必要になる可能性が高い。イランのメディアはすでに、2029年1月に始まるトランプ後の外交について論じている。

トランプの考えに対するGCC諸国の意見： クライアントは、エスカレーションに反対する湾岸諸国の助言がトランプに影響を与えるかを尋ねた。GCC諸国の指導者であるMBS、アラブ首長国連邦（UAE）のザイド大統領（MBZ）、カタールのタミム首長は、そろって忍耐を求めている。しかし、米国内のエネルギー価格の推移と対立状態を維持する戦略の失敗を踏まえると、彼らの助言が受け入れられ続ける可能性は低いだろう。
